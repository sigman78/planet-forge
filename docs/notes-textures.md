# Texture pack notes

Generated by `tools/fetch_textures.py` (run from `tools/`: `uv run python -I fetch_textures.py`). Edit the `LAYERS` table at the top to swap assets or retune per-layer settings; raw downloads are cached in `tools/raw/<source>_<id>/` (gitignored). Layer order = splat channel = `LAYERS` in `src/core/types.ts`.

Direction: small rocky worlds. The renderer applies per-world colour tints per layer, so every albedo is deliberately near-neutral (grey-beige).

Albedo processing (`neutralize()`): sRGB to linear, desaturate in linear space to the kept fraction, pull the mean hue 60% toward a grey-beige (1.0, 0.95, 0.86), optional luminance contrast scale, then a single gain (bisected, with clipping) so the mean linear albedo hits the target. Detail structure is preserved. Manifest `meanAlbedo` is measured from the saved JPEG; manifest also records `saturationKept`.

Other notes:
- Sources are the 2K-JPG zips, downsampled to 1024 with LANCZOS. Normals use NormalGL (renormalized after resize). Height is percentile-normalized (0.2 to 99.8). ORM: AO, roughness, metalness 0. Ice002 has no AO map (AO = 1).
- Search: ambientCG has no basalt/volcanic/salt/regolith keywords; assets were picked by browsing preview spheres of rock/ground/ice/clay results.
- `tileMeters` are hand-set guesses; tune in the renderer. Ice normals are subtle (smooth glassy surface); rock and basalt normals are strong and may want a lower normal scale.
- Obsolete layer files (beach_sand, grass, forest, dry_grass, desert, snow) are removed automatically by the script on a full run.
- Total size about 18 MB. Preview: `docs/textures_preview.jpg` (albedo and normal, 2x2 tiled).
